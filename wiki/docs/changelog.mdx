# Changelog

## 1.1 (Minecraft 26.x)

- Includes Trigger Lunge Swap.
- Works on Minecraft 26.x. Built against 26.2, so 26.1 and 26.3 are untested.
- Requires Java 25 and Fabric API. Quilt should work through Fabric compatibility, but is untested.

## 1.1 (Minecraft 1.21.11)

- Added Trigger Lunge Swap: swap to your spear, attack, then swap back.

## 1.0 (Minecraft 1.21 to 1.21.11)

- First release.
- Keybinds: Trigger Firework, Trigger Elytra/Armor Swap with a Swap/Revert toggle, Trigger Wind Charge, Trigger Pearl Catch, Trigger Air Pot and Trigger Pearl.

# Installation

## What you need

- Minecraft Java Edition, version 1.21 to 1.21.11, or any 26.x version
- Fabric Loader (0.19.3 or newer for the 26.x build)
- Fabric API
- Java 21 or newer for 1.21.x, Java 25 or newer for 26.x

## Which file to download

| Minecraft version | Mod version | Lunge Swap |
|-------------------|-------------|------------|
| 1.21 to 1.21.10 | 1.0 | No |
| 1.21.11 | 1.1 | Yes |
| 26.x | 1.1 | Yes |

## Steps

1. Install Fabric Loader for your Minecraft version.
2. Download Fabric API and put it in your mods folder.
3. Download the Ez Mace Keybinds file that matches your version.
4. Put it in the same mods folder.
5. Start the game and open Options, Controls, Key Binds to check that an Ez Mace Keybinds category appears.

## Notes

The mod is client-side only. Servers do not need it.

Quilt may work through its Fabric compatibility, but it has not been fully tested. Forge and NeoForge are not supported by the Fabric files.

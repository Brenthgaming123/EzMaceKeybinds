# Introduction

Ez Mace Keybinds is a client-side Fabric mod that turns the fiddly hotbar juggling behind mace and elytra PvP into single keypresses.

Every keybind is **unbound by default**. Set them under **Options > Controls > Key Binds > Ez Mace Keybinds**.

The items you use must be in your **hotbar** (slots 1-9). If an item is missing, the keybind does nothing.

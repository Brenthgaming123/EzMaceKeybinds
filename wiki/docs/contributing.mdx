# Contributing

## Requests

- **New features:** open a **Feature** issue on GitHub.
- **Another Minecraft version:** open a **Version Port** issue. Versions lower than 1.21 will not be ported.
- **Questions or comments:** open a **Message** issue.

## Building from source

Each folder under versions in the repository is a standalone Gradle project. Open the folder for your version and run `gradle clean build`. The jar is written to `build/libs/`.

The 1.21 builds need Java 21 or newer. The 26.x build needs Java 25 or newer and Gradle 9.8 or newer.

# Supported versions

| Build | Minecraft | Mod version | Lunge Swap | Java |
|-------|-----------|-------------|------------|------|
| 1.21.x | 1.21 to 1.21.11 | 1.0 | No | 21 or newer |
| 1.21.11 | 1.21.11 only | 1.1 | Yes | 21 or newer |
| 26.x | any 26.x version | 1.1 | Yes | 25 or newer |

## Loaders

- **Fabric:** supported
- **Quilt:** should work through Fabric compatibility, but is not fully tested
- **Forge and NeoForge:** not supported by these files

## Testing notes

The 26.x build was compiled against Minecraft 26.2. It is set to load on every 26.x version, but 26.1 and 26.3 have not been tested.

The mod uses no mixins, so it does not patch game code and is not expected to conflict with other mods. This has not been tested exhaustively.

## Need another version?

Open a **Version Port** issue on GitHub. Versions lower than 1.21 will not be ported.

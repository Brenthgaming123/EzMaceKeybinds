# Setup

Every keybind is **unbound by default**, so nothing interferes with your controls until you set them up.

## Binding your keys

1. Open Options, then Controls, then Key Binds.
2. Scroll to the **Ez Mace Keybinds** category.
3. Bind each action to the key you want.

## Put your items in the hotbar

The mod only looks for items in your hotbar (slots 1 to 9). If an item is missing from the hotbar, its keybind does nothing.

After a sequence finishes, the mod switches you back to the hotbar slot you started on.

## One sequence at a time

While one sequence is running, the other keybinds are ignored until it finishes. This stops you from overlapping them by accident.

## No config file

There is no config file. Everything is set in the Controls menu.
